# 颠勺王

微信小游戏。客人点菜，你在砧板上备料，再看火候颠勺，出锅夹一张手账。副标题是「今晚六桌」。

## 一桌怎么走

1. 主页看通关 x/6、今日最佳、橱窗。前三道先开：番茄炒蛋、蒜蓉油麦菜、扬州炒饭。
2. 接单。客人只给时限，偶尔加一句忌口，比如少辣。超时可以免费重做。
3. 砧板点对原料。点错三次，或时间到还没备齐，这单失败。
4. 炒。提示写「颠」时再颠，均匀上涨；写「停」时还猛颠，糊边上涨。评分看这两条和下料时机，不看颠了几次。模拟器用手动颠勺。真机在听到晃动时，传感器和按钮是同一条规则。
5. 出锅给出翻车、及格、招牌或神菜。翻车不进橱窗，也不覆盖这道菜的更高分。及格才记通关。招牌和神菜可以进橱窗，每道只留最高的一盘。
6. 每一锅都夹一张竖屏手账：菜名、评级、吐槽。科普只有一句，做法长文在菜册。分享是自愿的。
7. 前三道都至少及格一次，才解锁鱼香肉丝、宫保鸡丁、葱爆羊肉。六道都及格，出锅页可以看通关。

第一单会有三句带教。连点右上角红印 5 次，或预览参数 `qa=1`，炒的时候可以看当前段的参数。

清单 `assets/manifest.json` 由 `game.js` 用 `readFileSync` 读取，不要 `require` json。`dist/` 要提交，开发者工具读的是编译结果。没有真图时，画面用撕纸、色块和手写字体风的字。
