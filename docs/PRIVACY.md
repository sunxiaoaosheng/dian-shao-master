# 隐私指引里要声明的传感器

颠勺只在「炒」这一屏读取晃动，用来判断这一下该不该颠。不上传原始采样，不做账号，不靠网络才能把菜炒完。

用测试号登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)，打开 **设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引**，声明：

- **方向传感器**，对应 `wx.startDeviceMotionListening`
- **加速传感器**，对应 `wx.startAccelerometer`

没声明时，接口会直接失败（常见 errno 112），系统不会弹出授权。对局里会写「没收到晃动数据，先用手动颠勺」，并留下 **再听一次**。手动和传感器用的是同一套均匀 / 糊边规则。

iOS「设置 → 微信」里没有运动开关。游戏不会打开那一页。

声明可以写成：读取设备方向和加速度，只为判断颠勺，不上传原始数据。

保存指引后，重新编译、重新预览，再开一锅或点再听一次。
